# Question Pools for Ham Test

This repo contains the question pools for Ham Test. It's based off of [Russ Olsen's ham radio question pool](https://github.com/russolsen/ham_radio_question_pool), which, in turn is the question pool from the [NCVEC](https://ncvec.org/).

## Contributing

### EXPLANATIONS WANTED!

I'm trying to get explanations for *all* of the questions in the pools. These should be **original** 
and not be copied from another site like HamStudy, as those are not licensed for open source use. Instead, they should be your original work.

### Corrections

Corrections to the question pools **should not be made here**, unless it doesn't match the NCVEC pool. In the case of incorrect data, feel free to create an issue or pull request here or [upstream](https://github.com/russolsen/ham_radio_question_pool).

If you create an issue or pull request upstream, I would appreciate it if you make an issue or pull request here so I can update the question pools in this repo.

### Images

Images are missing, on purpose. For now at least. In the two Ham Test repos I have them added independently and plan to keep it that way as there are different requirements for loading the images.

### AI Usage

**Please *do not* use AI to write explanations.** We're trying to get **human written** explanations.

## Question pool effective dates

The **Technician** question pool is valid through **2026-2030**.

The **General** question pool is valid through **2023-2027**.

The **Amateur Extra** question pool is valid through **2024-2028**.
